# 06 — 分层架构与毕业考（2026-10-26 – 27，9.0）

## 从「保证」到「否决」

天花板期之后，最重要的一次认知转变：

**不再承诺「一定改好」，改成承诺「坏的不出去」。**

这个转变写进了 `docs/ROADMAP-9.0.md`：

> 明确不承诺：对任何原稿保证指定 AI 侦测分数；保证所有学术质量指标零退步。
>
> 北极星问题（每次交付都要能回答）：
> **这次改写改善了什么、改坏了什么、哪些结论有证据支持、什么情况下应该停止改写。**

## L0 – L5 六层

```text
L0 路由层    原稿状态分诊 → 决定干预深度与允许的改动类型
L1 诊断层    特征引擎 → 带证据的问题清单，不是目标剖面
L2 处理层    论证骨架约束下的语言处理（候选/手术/重组/研磨）
L3 验证层    多目标否决制评估（内容正确性独立于语言自然度）
L4 记录层    版本账本：每次改动的前后/内容差/检查结果/回退点
L5 校准轨    逐族轴校准、金丝雀、盲评、研究假说验证
```

### L0 五状态

| 状态 | 特征 | 路由 |
|---|---|---|
| S1 | 论证完整 + 语言可信 | 保守编辑（LT + 格式 + 引用检查），改动 ≤5–8% |
| S2 | 结构完整 + 语言不自然 | 8.18 全链 |
| S3 | 内容重复／论证薄弱 | **先论证重组，后语言处理** |
| S4 | 大量 AI 且缺作者分析 | **退回作者补充**，管线不静默代工 |
| S5 | 引用／事实来源不明 | **先核实，不润色**（停改令） |

**S4 的路由是一次重要的自我约束**：承认这类文档管线做不了，退回去。
这与天花板期的结论独立收敛。

### L3 三环否决

三道独立的否决环：
1. 内容正确性（数字/引用/事实）
2. 论证骨架存活
3. 语言自然度

**任何一环不过 → 回退到上一个绿点。**

### L4 版本账本

每次改动都记录：前文本、后文本、内容差、检查结果、回退点。

这让「改坏了什么」变成可查的事实，而不是事后猜。

## 毕业考（2026-10-27）

E2 走 arch90 全链：

```
Turnitin AI 0% / 查重 22%（族带内）/ 0 integrity flags
校准集第 22 点，码 49C86925C8
```

交付的是**否决环回退链的产物**：首选文本被拦 → 回退最佳绿候选。

这是 9.0 的核心价值：**交付的东西可能不是「最好的」，但一定是「过闸的」。**

## 第 24 课：双特征定律

九点对齐后，单特征 gen 映射被否决：

```
0.529 → 0%
0.749 → 0%
同 gen 41% / 98%
```

**单看 gen 完全无法预测。** 双特征规则 9/9 吻合：

> CV ≥ 0.54 → 全过（与 gen 无关至 0.69）
> CV 0.38–0.39 → gen 决定（0.76 过／0.98 败）
> CV ≤ 0.28 → 败

这条定律在 10.0 被重新检验——见 [08-v10.md](08-v10.md)，
新引擎族的下限是 **0.42**，不是 0.54。

## 第 22 课（9.0 毕业考版）：否决环抓出自己三个误报

> 9.0 毕业考：否决环拒绝了四轮有缺陷的交付
> （含评估器自身三个误报类被逐一逼出修复：量词 one 对称、half↔50%、
> 引用对齐基准、序数词 twenty-first↔21st、集合语义），
> 最终交付的回退产物 0%。

这里的关键是：**否决环自己也会误报**。修评估器和修管线一样重要。

这条经验在 10.0 直接复现了一次——第 5 节的质检修补（`missing_number` 误判
`45%` vs `forty-five percent`，救回 356 对训练数据）。

## 9.0 的边界（诚实版）

即使有了 L0–L5，9.0 仍然受限于引擎：

- S4 文档仍要靠作者补充
- 语域保持重生对纯 AI 高层文本无效
- 中英语种零覆盖

**9.0 解决的是「如何不交付坏的」，没解决「如何做出好的」。**

后者需要换引擎——这就是 10.0 的起点。
